《汇报有方——智能日报/周报》平台 · Windows 本机版

适用系统：Windows 10 / 11，64 位。无需安装 Python、Node.js 或其他开发工具。

1. 将整个文件夹解压到任意位置，不要只复制其中的 EXE。
2. 双击“汇报有方.exe”，网页会自动在默认浏览器中打开。
   如果没有自动打开，请复制程序窗口中 URL 后的地址到浏览器。
   默认使用 http://127.0.0.1:8000/；端口被占用时自动改用其他本地端口，以程序窗口显示为准。
3. 点击右上角头像，填写自己的个人信息和模型 API 配置。
4. API Key 保存后会在本机加密，重启程序无需再次填写。模型设置中可更换或清除 Key。
   请从模型服务商复制真实的 API Key，不要填中文说明或密码遮罩。生成汇报需要联网及可用的模型额度。
5. 选择日期，上传成果或填写工作内容，生成后核对并保存日报；周报会关联对应周内已保存的日报和成果。
6. 使用完毕后关闭程序窗口即可停止服务。

个人配置、日报和附件存放在当前 Windows 账户的 %LOCALAPPDATA%\汇报有方\，不在程序安装目录中。
更新程序时先退出旧程序，再替换程序文件夹；保留用户数据目录即可继续使用原配置和汇报。
换电脑或 Windows 账户后，通常需要重新填写 API Key。可在模型设置中点击“测试已保存配置”检查连接。

此分发包不包含开发者的 API Key、个人配置、日报或成果文件。每位用户需要配置自己的模型服务。
程序只监听当前电脑的 127.0.0.1，不需要以管理员身份运行。
此包适用于 Windows 64 位；macOS、Linux 及 Windows ARM64 原生运行需要另行构建。
